# Jarvis AI Assistant

A beginner-friendly AI voice assistant built with Python.

## Features

- Voice recognition
- Text-to-speech
- Open websites and apps
- AI responses using DeepSeek/OpenRouter
- Wake word support
- Continuous listening
- Windows compatible

## Commands

- Open YouTube
- Open Google
- Open Calculator
- Open Notepad
- Tell time/date
- AI questions

## Tech Used

- Python
- SpeechRecognition
- pywin32
- Requests
- OpenRouter API

## Run

`bash
py -3.12 main.py
